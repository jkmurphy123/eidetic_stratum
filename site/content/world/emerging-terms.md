# Emerging terminology (not yet a canonical glossary)

The versioned source read by the assisted-drafting pipeline is `emerging-terms.v1.json` in this directory. This original markdown is retained as an editorial note; update the JSON after approving a proposed term. Draft-side proposals remain in each ignored `drafts/<run-id>/proposed-terms.json` until reviewed.

- Eidetic Stratum — the deeper reality investigated beneath familiar appearances (established premise).
- Eidetician — investigator of the Stratum (established premise).
- Prime Referent — first established probe reference point (established premise).
- Eidetic Interstice — an area or interval of special surveying interest (established premise; precise definition to be settled later).

New terms coined in subsequent stories should be recorded here for editorial continuity before a formal glossary is approved.
